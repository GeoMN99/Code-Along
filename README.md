# Address Book & To Do List

### Author
George Ngunjiri

### Description
A JavaScript project that practices creating objects using constructors and prototypes. It includes two separate applications — an Address Book where you can add, view and delete contacts, and a To Do List where you can add, complete and delete tasks.

### Technologies Used
- HTML
- CSS
- JAVASCRIPT

### Setup Instructions
1. Clone this repository or download the ZIP file
2. Open the project folder
3. Open 'index.html' in your browser to use the Address Book
4. Click the link on the page to go to the To Do List
